Executive Summary

FarMinds is an innovative mobile application designed to empower farmers with AI-driven pest detection capabilities. By leveraging advanced computer vision technology through Mistral's Pixtral model, the application enables farmers to instantly identify insects and pests by simply taking a photograph. The system goes beyond identification by creating a collaborative network that automatically alerts farmers in the same region when threats are detected, fostering a community-driven approach to agricultural pest management.

Project Status: Production-ready | Last Updated: August 2026

Key Features

🔍 AI Insect Detection

Powered by Mistral Pixtral Vision AI, instantly identifies insect species from photos with high confidence scores.

📍 Regional Alerts

Automatic notifications to farmers in the same region when pests are detected, enabling proactive response.

📊 Detection History

Complete tracking of all previous detections including species, confidence levels, and risk assessments.

🔔 Push Notifications

Real-time alerts via Firebase Cloud Messaging to keep farmers informed instantly.

🗺️ Multi-Region Support

Currently supports Occitanie, Nouvelle-Aquitaine, and Bretagne regions in France.

📱 Cross-Platform

Available on both iOS and Android through React Native and Expo framework.

Architecture Decisions & Design Patterns

Backend Architecture

  • Async SQLAlchemy: Non-blocking database operations provide better performance and scalability under load
  • Service Layer Pattern: Business logic separated from route handlers following Single Responsibility Principle
  • Repository Pattern: Data access abstracted through dedicated service classes
  • Pydantic Schemas: Type-safe request/response validation with automatic API documentation
  • Dependency Injection: FastAPI's built-in DI system for database sessions and services
  • JWT Authentication: Stateless authentication using secure token-based approach
  • Middleware Pattern: Authentication and request processing handled via middleware layer

Frontend Architecture

  • Component-Based Design: Reusable UI components following React best practices
  • Context API: Global state management for authentication
  • Custom Hooks: Encapsulated logic for API calls and state management
  • Type Safety: TypeScript for compile-time error detection
  • Navigation: Stack-based navigation with React Navigation

Security Considerations

  • Password hashing with Bcrypt (strong cryptographic algorithm)
  • JWT tokens with expiration for session management
  • HTTPS-only API communication
  • Input validation on both client and server side
  • SQL injection prevention through parameterized queries (ORM)
  • Authentication middleware for protected routes

Use Cases & User Flows

Primary Use Case: Pest Detection & Alert

  1. Farmer spots unknown insect in their field
  2. Opens FarMinds app and navigates to detection screen
  3. Takes photo using camera or selects from gallery
  4. Image is uploaded to backend API
  5. Mistral Vision AI analyzes image and identifies species
  6. System determines risk level and generates recommendations
  7. Detection is saved to database with farmer's region
  8. All farmers in same region automatically receive push notification
  9. Farmers can view detection history and received alerts

Secondary Use Cases

  • Account Management: Registration, login, profile viewing
  • History Review: Browse past detections with filtering
  • Notification Management: View and mark alerts as read
  • Regional Monitoring: Track pest activity in specific regions
